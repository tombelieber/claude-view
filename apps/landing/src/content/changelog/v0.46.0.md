## New features

**Multiple Claude config directories.** Opt into additional config directories, then filter history by profile. Same-named directories keep separate identities and statusline commands. Primary transcripts take priority over copied files.

**Readable workflow tools.** Agent details pair structured tool calls with their outputs and preserve failures. The detail panel supports resizing on desktop and stacking on smaller screens.

## Fixes

- Select the most specific model price deterministically, including dated Fable and Mythos releases. Updated rates include Sonnet 5.5 cache reads at $0.10 per million tokens.
- Preserve model fallback metadata, omitted paste content and fork lifecycle events from newer Claude Code sessions.
- Resume a recently closed sidecar session and initialize forks without waiting for a new user prompt.
- Accept available plugin entries without an optional description and hide empty analytics before accessing scope metadata.
- Preserve unreadable or malformed Claude settings instead of replacing them during hook registration.

## Platform scope

macOS and Linux remain the published binary platforms. This release includes Windows-specific source compatibility work; a Windows binary and native runtime qualification remain pending.
